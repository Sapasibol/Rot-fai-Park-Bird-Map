ตอนนี้ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น ต่อคลาวด์แล้วทุกคนที่มีลิงก์จะเห็นเหมือนกัน และเพิ่มข้อมูลเข้ามาได้ด้วย

เอาเว็บขึ้นออนไลน์ให้คนอื่นเข้าดูได้

ทุกอย่างที่คุณตั้งค่าไว้ตอนนี้ (รูป · ชนิดที่เพิ่มเอง · ข้อมูล eBird · ขอบเขตสวน) เก็บอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น คนอื่นจะไม่เห็น
ต้องกด 2 ปุ่มข้างล่างเพื่ออบทุกอย่างออกมาเป็นไฟล์ก่อน แล้วค่อยอัปโหลด

ขั้นที่ 1 — อบไฟล์ออกมา

รูปที่ได้ชื่อ ชนิด.jpg กับ ชนิด_av.jpg — เอาไปวางทับในโฟลเดอร์ assets/birds/
ส่วน data.json วางไว้ข้าง ๆ index.html เว็บจะอ่านข้อมูลจากไฟล์นี้แทนการเรียก eBird สด ทำให้คนอื่นเปิดได้เร็วและไม่ต้องใช้ API key

ขั้นที่ 2 — อัปโหลด

Netlify Drop ง่ายสุด ลากโฟลเดอร์ทั้งอันไปวางที่ app.netlify.com/drop ได้ลิงก์ทันที ไม่ต้องสมัครก็ได้ ฟรี
GitHub Pages อัปโหลดเข้า repo แล้วเปิด Pages ในหน้า Settings เหมาะถ้าอยากเก็บประวัติการแก้ไข ฟรี
Cloudflare Pages ลากโฟลเดอร์เหมือนกัน เร็วในไทย รองรับคนเข้าเยอะ ฟรี

ทั้งสามแบบได้ลิงก์แบบ ใครมีลิงก์ก็เปิดได้ และไม่ขึ้นใน Google ถ้าไม่ได้ไปส่งให้ Google เก็บข้อมูลเอง
ข้อดีอีกอย่าง — พอขึ้นออนไลน์แล้ว การดึงขอบเขตสวนจาก OpenStreetMap จะทำงานได้ ต่างจากตอนเปิดไฟล์จากเครื่องที่มักโดนบล็อก

ขั้นที่ 3 — ปิดโหมดผู้ดูแล

เมื่อติ๊กแล้ว คนทั่วไปจะเห็นแค่แผนที่ ส่วนคุณกลับเข้ามาแก้ได้เสมอ โดยเติม ?edit ต่อท้าย URL
ข้อควรระวัง — API key ของ eBird ฝังอยู่ในไฟล์ ถ้าเว็บขึ้นออนไลน์ คนอื่นเปิดดูซอร์สโค้ดก็เห็น ควรขอ key ใหม่แยกไว้ใช้เฉพาะเว็บนี้ หรือถ้าใช้ data.json แล้วจะลบ key ทิ้งไปเลยก็ได้
